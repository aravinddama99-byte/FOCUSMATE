# FocusMate Android app (with app blocker)

Wraps your FocusMate HTML in a native Android app and adds a **Focus App Blocker** (shield button, bottom-right).

## Get the APK (no Android Studio needed)
1. Create a free GitHub account → New repository → upload everything in this folder (keep `.github`).
2. Open the **Actions** tab → "Build APK" runs automatically (or click *Run workflow*).
3. When it finishes, download **FocusMate-apk** → unzip → `app-debug.apk`. Copy to your phone and install (allow "Install unknown apps").

Or with Android Studio: open this folder → Build → Build APK(s).

## First use
Tap 🛡️ → "Open Accessibility settings" → enable **FocusMate App Blocker** → back in the app pick apps, choose a length, Start.
Blocked apps get bounced to a "Stay focused" screen until the timer ends. Strict mode removes the End button.
